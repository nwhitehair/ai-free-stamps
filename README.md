# AI-Free Stamps

This is a collection of graphics that you can use to indicate that you have produced something without the benefit of artificial intelligence (AI).

Using these stamps does not necessarily imply that you are fundamentally opposed to using AI, or even that you never use AI, but rather that you are proud of what you are able to achieve without it.

Rendered Images are provided as 512x512 PNGs and can be found in the [png](png/) subdirectory.

The art was created using [InkScape](https://inkscape.org/) and the original vector art files are provided in the [svg](svg/) subdirectory. You may use and modify these as you like, provided you adhere to the terms of the fairly permissive [license](LICENSE.md).
